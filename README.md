# 🎧 PDF to Audio Converter (Text-to-Speech)

Ce projet Python permet de **convertir automatiquement un fichier PDF en audio (format MP3)** en utilisant la synthèse vocale Google (gTTS).

---

## 🚀 Fonctionnalités

- Extraction automatique du texte depuis un fichier PDF.
- Conversion du texte en audio avec la voix française naturelle de Google.
- Export du fichier final au format `.mp3`.
- Fonctionne sur tout système (Windows, macOS, Linux).

---

## 🧩 Prérequis

Assurez-vous d’avoir **Python 3.x** installé sur votre machine.
